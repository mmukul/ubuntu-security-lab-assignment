# Ubuntu OS Automation with Packer

## Overview

This project automates the deployment of an Ubuntu OS using HashiCorp Packer and Oracle VirtualBox.

The solution provisions a fully configured Ubuntu virtual machine with:

- Ubuntu Server 24.04 LTS
- SSH Access
- Docker Engine
- Docker Compose
- Greenbone Community Edition (OpenVAS)
- Security administration tools
- Automated provisioning using Infrastructure as Code (IaC)

The objective of this project is to demonstrate automated infrastructure provisioning, system configuration, and vulnerability management deployment using Packer.
